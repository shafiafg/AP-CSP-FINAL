## how to get api key
### step one: head over to google at studio https://aistudio.google.com/
### Step 2: after you log in look at the the bottom left corner you will see option for get api key press that https://aistudio.google.com/api-keys
### step 3: click creat api key if there isn't any and give it a name and a project if you don't have one create it (most of the times there is a default project)
### final step: copy the api key remove the .example from the .env.example file and replace the string in that file with your api key make sure its a string so it has these "" around them
